# CSV & Excel Data Cleaner with Quality Reporting

**Label:** Self-Initiated Demo Project

## Problem

Small teams often receive inconsistent spreadsheets containing repeated records, missing required fields, uneven column names, and extra whitespace. Manual cleanup is slow and makes it difficult to explain exactly what changed.

## Solution

I built a lightweight FastAPI and React workflow that cleans CSV and XLSX files without modifying the source. Users select required columns and duplicate keys, review clean and rejected rows, see a concise quality summary, and download reusable output artifacts.

## Deliverables

- Tested Python/FastAPI source code
- Responsive React web interface
- Fictional sample data
- Clean CSV export
- Three-sheet XLSX workbook with clean data, rejected rows, and quality summary
- Timestamped JSON quality report
- Local setup, testing, and evaluator guide

## Skills

Python, FastAPI, pandas, React, API Integration, Data Processing, Data Extraction
